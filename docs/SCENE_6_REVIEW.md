## 2. How the comparison works

- **Three kinds of comparison.** Universities (the 17 verified institutions), Courses (Scene 4's illustrative pathways), Programmes (a verified institution plus one of its confirmed courses). Up to three options per kind. The selection is shared with Scenes 4 and 5 (an option added there is already here) and survives a reload in the same tab.
- **Each cell says one of four things.** Verified (a source URL, the quoted text and the date we checked it), Orientation (course pathways only: general guidance with no source), Not verified (we have not confirmed it; the reason is stated), or Not applicable (the field does not exist for this kind of option, for example one fee for a whole university; also with a reason). Verified, Partially verified, Orientation and Not verified use the shared labels. Partially verified marks lists that show only what was confirmed (academic domains, available courses, "confirmed at").
- **What counts as a difference.** A parameter is marked "Verified values differ" only when it is comparable, at least two options have a verified value, and those values differ. A missing value never counts, a partial list never counts, and Orientation never produces a difference. So "no differences" never means "the same".
- **Missing information.** A parameter with nothing confirmed or only "not applicable" for every chosen option is not drawn as an empty row. It is listed once under "What we cannot tell you yet", with its reason, split into Not verified and Not applicable. Every parameter appears either as a table row or in that list.
- **No ranking.** There are no scores, ranks, totals or winners. Programmes built on different kinds of degree are flagged as possibly not alternatives, not hidden.
- **Views.** All parameters, Verified parameters, Differences only, and a chooser to switch parameters or whole groups off.
- **Phones.** The table becomes one block per parameter, each value named by its option.
